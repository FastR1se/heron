# g1_upper_reach — задача обучения закреплённого G1

Вторая реализация конвейера фазы 6 (ADR-0040) на задаче ADR-0005 п. 1: политика верха тела
гуманоида. Пакет, точка входа, сцена — ни одного файла ядра, как у задачи `arm6_reach`.

Робот — `g1_29dof_lock_waist_rev_1_0_mounted`: тело `mode_machine = 6` с тазом, привинченным к
стойке на 1.0 м описанием (ADR-P6A). Встроенного контроллера баланса нет ни в одном мире
платформы, его место занимает крепление — идеальное и бесконечно жёсткое. Это условие каждого
прогона, а не «баланс на встроенном контроллере»; цена записана в ADR-P6A, п. 6.

## Что задача объявляет

| Член | Значение | Откуда |
|---|---|---|
| `backend` | `isaaclab` | бэкенд, в словаре которого написаны награды |
| `spec` | навык `g1_upper_reach`, `arm.joint_position`, `dof == 15` | уходит в манифест артефакта (ADR-0046) |
| `completion` | допуск 0.08 рад по худшему суставу, выдержка 0.3 с, горизонт 5 с | один допуск в двух мирах (ADR-0043) |
| `goal_range` | поза отсчёта ± 0.3 рад у пояса, ± 0.5 рад у рук | внутри множества целей действия |
| `rewards` | слежение (среднее), бонус по худшему суставу, штрафы за скорость и рывок | награду пишет человек |
| `terminations` | только горизонт | эпизод не обрывается на успехе |
| `events` | ноги — в ноль и неподвижно; верх тела — поза отсчёта ± 0.8 рад, ± 0.2 рад/с | накрывает нулевую позу, в которой руки висят до первой команды |
| `agent` | сеть 128×128, остальное — бэкенда | 60 входов, 15 выходов |

**Чего задача объявить не может:** действие, наблюдение, частоты, привод и закрепление. Их задают
контракт и описание робота (ADR-0044, ADR-0048).

**Что задача знает о роботе:** имена суставов ног (их сбрасывает только она — никто их не ведёт) и
какой сустав — пояс. Это знание пакета, а не ядра.

## Установка и проверка

```bash
python examples/robots/g1_29dof_lock_waist_rev_1_0_mounted/fetch_description.py
pip install --no-deps -e examples/plugins/g1_upper_reach
heron task list
heron train run examples/scenarios/g1_mounted_train.yaml --registry examples/robots --dry-run
```

Сухой прогон печатает выведенную среду — физика 500 Гц, политика 50 Гц, decimation 10, база
закреплена описанием, действие шириной 15, наблюдение шириной 60, коэффициенты привода — и
команду процесса. Ни GPU, ни симулятор для этого не нужны.

## Обучение и исполнение

`scripts/phase6-stage7.sh` на Linux: высота таза в Isaac до обучения, обучение с порогом ADR-0005
снаружи процесса, экспорт, сверка артефакта в окружении исполнения, прогон в Gazebo через мост
навыком кодом и обученным (одна строка профиля) с записью, сравнение по записям.
