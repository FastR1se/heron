# ADR-0077. Ученик появляется в `pose` сценария

**Статус:** принято; дополняет [ADR-0044](0044-training-task-is-the-sixth-extension-point.md), для [ADR-0075](0075-g1-learns-to-stand.md)
**Дата:** 21.09.2026

## Контекст

- Корень артикуляции Isaac появляется в `init_state.pos`, по умолчанию `(0, 0, 0)`. Для закреплённых
  роботов это верно: высоту задаёт описание (ADR-0063). Свободный G1 в нуле — таз в полу.
- Сценарий уже несёт `pose` участника (`ScenarioRobot.pose`), и мир Gazebo ставит по ней робота
  (`humanoid.yaml`: `[0, 0, 0.8]`). У ученика поле было и не читалось.

## Решение

`TrainSpec.base_position` — `pose` ученика из сценария; процесс обучения пишет её в `init_state.pos`.
Сброс эпизода отсчитывается от неё (события задачи смещают вокруг). Умолчание сценария — ноль, так что
существующие сценарии обучения не меняются.

## Альтернативы

**Высота в задаче.** Задача не владеет сценой (ADR-0044); высота появления — свойство размещения, а оно в
сценарии. Отвергнуто.

**Высота из описания** (сумма звеньев до стопы). Кинематику платформа не выводит сверх нужного (ADR-0009),
и стойка с согнутыми коленями — не нулевая поза описания. Отвергнуто.

## Последствия

- Одна величина — одно место: размещение робота в мире и в обучении задаётся `pose` сценария.
- Печать сухого прогона показывает положение появления.
