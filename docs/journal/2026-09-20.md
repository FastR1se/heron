# Журнал сессии 2026-09-20

## Задача

Поставить автоматизации ассистента разработки: хуки, субагентов, навыки, MCP-сервер, плюс
механические проверки того, что до сих пор держалось на внимании человека.

## Сделано

1. **Хук `adr_immutable`** (`PreToolUse` на `Edit|Write`) — правило «карточка задним числом не
   правится» стало механическим. Карточка, уже закреплённая коммитом, не редактируется; исключение
   одно — строка `**Статус:**`, потому что замена решения записывается там и больше нигде.
   Проверен на четырёх случаях: правка тела закреплённой карточки — отказ; правка статуса —
   пропуск; новая карточка — пропуск; обычный файл — пропуск.
2. **Хук `ruff_edited`** (`PostToolUse`) — `ruff check --fix` на один изменённый файл в области
   линтера CI (`src`, `tests`, `examples/plugins`). Неисправимое возвращается сообщением, а не
   логом CI назавтра. Проверен: два неиспользуемых импорта убраны, файл вне области не тронут.
3. **Навык `/preflight`** — цепочка CI на Windows: линтер, `mypy` ядра и двух пакетов, набор ядра,
   наборы пакетов роботов и задач, CLI на dummy (валидация, `gen --check`, командный класс, отказ
   прогона на железе без шкалы, отказ потокового навыка на RC5, миссия комплекса), `bash -n` по
   установщикам. Полный прогон — 2 м 24 с, всё зелёное.
4. **Навыки `/adr` и `/journal`** — карточка со сквозным номером и пятью разделами; журнал на
   сегодня с подсказкой пустых разделов. Этот файл создан вторым.
5. **Субагенты `adr-check` и `single-source`** — сверка изменения с полными текстами карточек по
   таблице «путь → решения», и охота за вторым источником правды у величины.
6. **Два теста в `tests/test_invariants.py`:**
   - `test_every_decision_is_named_in_the_guide` — индекс в CLAUDE.md сверяется с карточками в обе
     стороны, с разбором сгруппированных строк (`**0035–0037**`, `**0052, 0057**`);
   - `test_decision_references_resolve` — каждая ссылка `ADR-NNNN` в `src`, `tests`, `examples`,
     `scripts`, `.github`, `docs/plans` указывает на существующую карточку.

   На текущем дереве: 71 карточка, 71 упомянутый номер, 207 ссылок, висячих нет.
7. **Карточка ADR-0072** «Дисциплина решений проверяется машиной, а не вниманием» — написана
   навыком `/adr`, строка в CLAUDE.md в группе «Окружение», рядом с 0071.
8. **`.mcp.json` с `context7`** — живая документация ROS 2 Jazzy, Isaac Lab 2.3, pydantic v2,
   CycloneDDS. Кэш npm уведён в `.npm-cache` репозитория: на C места нет.
9. **`.gitignore`** — `/.claude/settings.local.json` (абсолютные пути этой машины) и `/.npm-cache/`.

## Проблемы и тупики

- **Первая проба хуков ничего не проверила.** Тестовый JSON собирался в командной строке Git Bash,
  оболочка съела обратные слэши путей Windows, и хук трижды подряд ответил «не отработал; правка не
  проверена» с кодом 0. Выглядело как «всё пропускается». Payload пришлось собирать скриптом
  (`_scratch/hook_probe.py`) — это же подтверждение записи в памяти о heredoc в Git Bash.
- **Исключение для строки статуса сначала не работало.** Хук искал строку, начинающуюся с `Статус`,
  а карточки пишут `**Статус:** принято`. Нашлось не тестом, а чтением настоящей карточки 0071:
  правило писалось по памяти о форме, а не по форме. Исправлено снятием `*` перед сравнением.
- **Проверка ссылок на карточки сначала дала 100+ ложных срабатываний** — `grep -r` прошёлся по
  `__pycache__` и напечатал «Binary file … matches». В тесте каталоги `__pycache__` и `.pyc`
  исключены явно.
- **GitHub MCP не поставлен.** Нужен токен пользователя, а `gh` на машине нет. Пользователь выбрал
  ставить `gh` CLI (`winget install GitHub.cli`) — без ручного токена; ставится отдельно.
- **`PYTEST_ADDOPTS` с обратными слэшами создал каталог-мусор в корне** —
  `PROJECTSROBOTICS_PLATFORM2.pytest-tmp/`. Причина: pytest разбирает эту переменную через
  `shlex`, а тот съедает `\` как экранирование. Заметил только по `git status`, потому что
  каталог не попал ни в один ignore. Путь переписан прямыми слэшами.

## Наблюдения

- `Path.rglob` на несуществующем каталоге возвращает пустой список, не исключение — поэтому
  `test_decision_references_resolve` переживает задание CI «ядро без роботов», где `examples/`
  удалён. Проверено отдельно, а не предположено.
- Полный набор ядра — 72,7 с, пакеты роботов — 23,7 с, линтер — 0,1 с. Отсюда и разделение:
  ruff в хуке на каждую правку, всё остальное — в `/preflight` руками.
- Индекс решений в CLAUDE.md оказался полным: все 71 карточки названы, включая те, что спрятаны
  в сгруппированных строках. Тест здесь не чинит расхождение, а удерживает от него: перенумерация
  фазовых карточек (`ADR-P8A…P8F` → `ADR-0065…0070`) уже была.
- Оба новых теста проверены с отрицательной стороны: на подброшенной карточке без строки и на
  ссылке в никуда они падают. Зелёный тест, который не умеет краснеть, — украшение.
